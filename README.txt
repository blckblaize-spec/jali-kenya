JALI KENYA WEBSITE — STARTER PACKAGE

Files:
- index.html: responsive one-page website prototype.

How to preview on Android:
1. Download and extract this ZIP using your phone's Files app.
2. Open index.html in a browser (Chrome may require a file manager's Open with option).
3. To publish it, upload index.html to a static host such as GitHub Pages or Netlify.

Important:
- The registration form is a front-end demo. It does not transmit or save personal information.
- There is no real member login, database, admin dashboard, payment processing, or M-Pesa integration yet.
- Before accepting members or contributions, add a secure backend, data protection/privacy notice, approved membership rules, contact details, and payment integration.
- Jali Kenya name availability has NOT been confirmed. Check the relevant official registry before using the name publicly.
- This is an original design inspired by the general family-welfare website concept, not a copy of KUPA Kenya.
